# 十交易所整合网格交易机器人

一个在 Windows 10/11 64 位电脑本机运行的多交易所永续合约网格机器人，统一接入 Decibel、Extended、RISEx、Arcus、Robinhood Chain Lighter（RHC）、N1、Phoenix、Phoenix2、Nado 和 PopDEX，提供中文网页仪表盘、模拟盘、实盘、趋势分析、订单对账、崩溃恢复、代理和可选 AI 助手。

> [!CAUTION]
> 这是交易软件，不是收益保证或投资建议。`live` 会使用真实账户、真实保证金并发送真实订单，可能产生手续费、资金费、滑点、强平或全部损失。第一次使用必须保持所有交易所为 `paper`；确认功能和配置后，再用小额资金逐个启用实盘。

## Windows 三步启动

1. 下载源码 ZIP 并完整解压。不要直接在压缩包预览窗口中运行。
2. 双击根目录的 `一键启动.bat`。
3. 等待浏览器自动打开 `http://127.0.0.1:8283`。

首次启动会自动完成这些工作：

- 从 `.env.example` 生成安全的 `.env`，十个交易所默认全部为 `paper`；
- 检查 Node.js 20+；电脑没有 Node.js 时，从 `nodejs.org` 下载并校验官方 LTS 便携版到项目内 `.runtime`，无需管理员权限；
- 按 `package-lock.json` 安装完整依赖；
- 仅当 `LR_MODE=live` 时准备 Python 3.12 和官方 `lighter-sdk`；没有兼容 Python 时会下载经过 SHA-256 校验的官方便携包到项目内，不调用 Windows Installer、无需管理员权限；
- 在不连接交易所、不输出密钥的前提下检查配置格式；
- 启动本地服务器并打开仪表盘。

保持启动窗口开启。关闭窗口或按 `Ctrl+C` 会停止本机程序，但交易所已经接受的实盘挂单不会因为窗口关闭而自动消失；应先在仪表盘执行“停止 + 撤单 + 平仓”，并到交易所官网复核。

## 主要功能

- 十所统一总览，区分实盘与模拟盘权益、盈亏、成交量、完成格数、持仓和健康状态；
- 中性、做多、做空三种等差网格；
- 15 分钟、1 小时、4 小时、1 天 K 线趋势判断和稳健/激进智能参数；
- 启动前保证金预检、手续费与格距提示、杠杆上限、真实挂单对账和失败安全重试；
- 调整区间、手动补格、撤单保留持仓、停止并平仓、统计重置；
- 未托管持仓的只减仓回收阶梯、按现价重开网格或市价平仓；
- 进程重启后根据 `.state.json` 接管上次运行中的网格；
- HTTP(S)/SOCKS5 代理和出口 IP 检测；
- 可选 AI 风控哨兵、出区间建议、多周期市况分析、日报、通知和需人工确认的对话操作。

## 安全默认值

- `.env.example` 不含任何凭据，所有交易所默认 `paper`；
- 服务默认只监听 `127.0.0.1`，仪表盘不应直接暴露到公网；
- `.env`、`secrets/`、`.state.json`、运行时、依赖缓存和日志均已加入 `.gitignore`；
- 程序没有提现、转账或修改 API key 的页面和本地 API；
- AI 只能提出白名单操作，必须由用户在网页确认后才调用正常交易接口；
- 一键启动检测到端口被其他程序占用时不会关闭对方，而是提示修改 `PORT`。

## 开发者运行

需要 Node.js 20 或更高版本：

```powershell
Copy-Item .env.example .env
npm ci
npm run check:config
npm test
npm start
```

`npm ci` 会严格使用锁文件版本。RHC 实盘还需要 64 位 Python 3.12；Windows 用户直接使用一键启动器即可自动准备项目内便携环境。
